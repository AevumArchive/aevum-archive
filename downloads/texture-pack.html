Adding packs later

To add a new bundle manually, place the zip inside assets/texturepacks/, then add or update a download card on this page with the new file name.

  • Keep the file name simple, like playthrough-addon-v2.zip.
  • Use a normal link to /aevum-archive/assets/texturepacks/file-name.zip.
  • Commit and push the change, then GitHub Pages will publish it.
