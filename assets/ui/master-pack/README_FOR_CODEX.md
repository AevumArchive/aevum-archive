## Codex integration rules
- One PNG = one UI asset.
- Transparent background.
- Do not replace character portraits or portrait icons.
- Keep names, PL values, countdowns, descriptions, labels, and other text in HTML/CSS.
- Aevum style = antique gold + black/charcoal + deep violet/amethyst.
- Chains indicate Locked / restricted states, not normal Sealed character records.
