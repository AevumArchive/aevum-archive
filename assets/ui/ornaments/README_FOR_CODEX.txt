AEVUM ARCHIVE — CODEX NAMED UI ORNAMENT PACK

This pack is a Codex-friendly version of the individual ornament PNGs.
Every file has been renamed clearly so it is obvious where it belongs in the Aevum Archive website.

GENERAL RULES
- All files are transparent PNGs.
- One ornament per image only.
- No character borders and no character portraits.
- These are small decorative UI assets for the dark fantasy archive site.

FOLDER GUIDE

01_Global_Header_Hero
Use for the homepage hero, major landing headers, and large archive banner sections.

02_Global_Edge_Ornaments
Use as left/right page edge ornaments or long vertical rails on large desktop layouts.

03_Global_Dividers
Use to separate sections, cards, major content blocks, and archive shelves.
- micro = short divider
- long = major section divider
- magic_wisp = special mystical divider

04_Global_Progress_and_Loading
Use for progress bars, loading indicators, reveal states, sync states, or unlock progress.

05_Global_Status_Indicators
Use for badges, pills, inline markers, small indicators, metadata rows, and decorative state icons.

06_Global_Magic_Effects
Use as accent effects around important UI blocks, highlighted states, or ritual/magical emphasis.

07_Lore_Archive_Sealed_Records
Best used on lore pages, archive record entries, sealed record cards, and archive metadata sections.

08_Events_Fallen_and_Danger
Best used on events, world-events, fallen records, dangerous notices, corrupted/damaged sections.

09_Downloads_Seals_and_Misc
Best used on downloads pages, texture-pack pages, release notes, special archive notices, and document-style callouts.

SUGGESTED PAGE PLACEMENT
- Homepage: hero flourish, long dividers, archive orb seal, status rings, micro dividers
- Playthroughs: magic wisp divider, long dividers, subtle status markers
- Characters / characters/all: only generic dividers and subtle indicators if needed
- NPCs: archive moon seal, lore dividers, candles if atmospheric styling is needed
- Lore: moon seal, crescent medallion, violet corner ornament, hanging tassel, candles, long violet divider
- Events / world-events: crimson flame, crimson corner ornament, candles, long dark divider
- Achievements: gold divider, gold status ring, gold gem markers, golden flame accents
- Downloads / texture-pack page: sealed scroll, wax seal, gold divider, gold progress bar

NAMING LOGIC
ui_[scope]_[area]_[object]_[variant].png

Examples:
- ui_global_divider_long_violet.png
- ui_lore_archive_moon_seal.png
- ui_events_fallen_corner_ornament_crimson.png
- ui_downloads_sealed_scroll.png

If Codex places assets automatically, the folder name + filename together should make the intended purpose obvious.
