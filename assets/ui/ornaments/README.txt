AEVUM ARCHIVE — INDIVIDUAL ORNAMENTS

Each PNG contains one ornament / one UI decoration only.

- Micro and long dividers
- Progress bars
- Arcane flames
- Seals / rings / medallions
- Gem markers
- Corner pieces
- Candle cluster
- Sealed scroll
- Wax seal
