# Generated ornament concepts

These two files are visual direction studies created with the built-in image generation mode on 2026-08-17.

They are not loaded by the website. The generator baked a checkerboard into RGB pixels instead of returning genuine alpha, so they are reference-only and must not be used as overlays. Production assets must pass the alpha checks in CHATTI_ORNAMENT_PRODUCTION_BRIEF_V3.md.

- sealed_corner_concept_reference.png: smoked silver, amethyst enamel, restrained magenta crystal.
- fallen_corner_concept_reference.png: blackened iron, oxblood enamel, restrained ruby memorial accent.

The shipped live frame uses responsive CSS geometry and contains no stretched raster pixels.
