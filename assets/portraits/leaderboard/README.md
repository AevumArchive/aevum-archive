To add or replace a portrait, upload a WebP image with the exact matching filename into this folder. No HTML or CSS change is required.

Recommended artwork:

- Portrait ratio: 2:3
- Recommended source size: 1200 x 1800 pixels
- Keep faces and important details inside the central 80% safe area
- Use WebP with a dark or transparent-compatible background
- Do not add text, rank numbers, UI frames or profile icons to the artwork

The page crops with `background-size: cover`. Replacing a file with another image using the same filename updates the slot automatically after deployment and cache refresh.
